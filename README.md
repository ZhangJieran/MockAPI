## 环境配置

请确保设备上有 Edge浏览器 和 <a href="https://github.com/farion1231/cc-switch">CC Switch</a><br>



**安装python环境**

```bash
uv sync
```

**CC Switch开启本地路由**

- 
-

**CC Switch ClaudeCode配置**

|配置项|配置方法
|---|---
|请求地址|http://localhost:xxxx<br>请把官网链接指向本项目后端服务，端口号与后端服务端口一致
|高级选项->上游格式|Open Chat Completions(需开启路由)
|高级选项->完整URL|开启
